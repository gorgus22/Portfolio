# Video da caricare su YouTube (non in elenco)

Carica i video su YouTube come **Non in elenco**. Poi, in `src/data/projects.ts`, sostituisci il media Drive così:

```ts
// prima
{ type: 'drive', url: 'https://drive.google.com/file/d/…', caption: '…' }
// dopo
{ type: 'youtube', url: 'https://youtu.be/CODICE', caption: '…' }
```

Oppure mandami la lista dei link e lo faccio io. I file che sono immagini (render statici) possono restare su Drive.

**Descrizione da usare per tutti** (cambia solo la prima riga):

```
<Titolo progetto> — <didascalia>

Giorgio Mascio (Gorgo) — Digital Artist & VJ
Portfolio: <link del sito>
Contatti: giorgiomascio13@gmail.com
```
